### 第一步：01. Jmeter Script（脚本升级）

你已经会做简单的，但要想接进 Jenkins，脚本需要满足几个**硬性要求**：

1. **参数化与变量化**：不要把环境地址、账号密码写死在脚本里。使用 `${__P(host,默认值)}` 读取外部参数，这样 Jenkins 上可以传不同的环境参数。
    
2. **输出报告格式**：必须配置 **Summary Report** 或 **Aggregate Report** 监听器，并且把输出结果保存为 `.jtl` 文件（这是 Jenkins 解析的基础）。
    
3. **断言与提取**：确保接口有响应断言（比如验证 HTTP 200 或包含某个字段），并且用 JSON Extractor 提取关键 Token，方便后续接口联动。
    
4. **命令行运行**：习惯在本地用命令行跑一下：`jmeter -n -t test.jmx -l result.jtl -e -o report`（无界面运行），确保脚本稳定。
