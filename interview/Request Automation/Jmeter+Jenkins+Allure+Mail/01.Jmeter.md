5.正则表达式/JSON提取器+JSR后置处理器+JSR预处理程序
a.正则表达式先获取变量值，然后使用后置处理器将变量变成全局系统变量。然后再用JSR前置处理器获取全局系统变量再进行使用

b. JSR后置处理器：Groovy（阁汝v） 
def myToken = vars.get("P_token")  
  
// 如果 token 不为空，把它设置成全局属性  
if (myToken != null) {  
    props.put("GLOBAL_TOKEN", myToken)  
    log.info("✅ 全局 Token 已设置: " + myToken)  
} else {  
    log.warn("⚠️ token 为空，请检查正则提取是否成功")  
}


c.JSR预处理程序（跨线程前置处理器）
// 从全局属性里取出 token（props 是 JMeter 的全局属性容器）  
def globalToken = props.get("GLOBAL_TOKEN")  
  
// 如果全局 token 存在，放入局部变量（vars），供当前请求使用  
if (globalToken != null) {  
    vars.put("GLOBAL_TOKEN", globalToken)  
    log.info("✅ 已从全局获取 token: " + globalToken)  
} else {  
    log.warn("⚠️ 全局 GLOBAL_TOKEN 为空，请检查是否已在 setUp 线程组中设置")  
}
