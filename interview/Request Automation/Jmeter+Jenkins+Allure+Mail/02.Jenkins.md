### 第二步：02. Jenkins（持续集成核心）

这一步是把你本地的脚本变成**自动定时执行**的任务。

1. **安装与插件**：安装 Jenkins 后，必装插件：`Performance Plugin`（用来读 JTL 分析性能）。
    
2. **新建任务（构建一个自由风格的软件项目）**：
    
    - 源码管理（如果脚本在 Git 上，拉取代码）。
        
    - 构建步骤选择 **Execute Windows batch command**（如果是Windows）或 **Invoke top-level Maven targets**。
        
    - 在构建命令里，用 `jmeter -n -t ...` 来调用脚本。
        
3. **Post-build Actions（构建后操作）**：选择 **Publish Performance test result report**，指向你的 `.jtl` 文件，这样 Jenkins 首页就能直接看到响应时间、错误率的折线图。
