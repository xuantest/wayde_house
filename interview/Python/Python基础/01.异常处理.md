异常处理情况
### 区别1：执行时机不同

> `if` 是在**执行前**做判断，`try` 是在**执行中**捕获异常。

python

if file_exists:     # 先判断，再执行
    upload_file()
try:                # 先执行，出错了再处理
    upload_file()
except:
    print("失败")

### 区别2：用途不同

> `if` 是用来做**业务分支判断**的，比如判断用户有没有权限、文件存不存在、数据格式对不对。
> 
> `try` 是用来做**异常处理**的，比如网络请求超时、数据库连接断开、读取文件出错。


### 区别3：能不能处理意外

> `if` **只能处理已知的情况**，你需要提前知道要判断什么。
> 
> `try` **能处理未知的意外**，不用提前预判，出错了就能兜住。

测试上传功能时，我会先判断**文件是否存在**（用 `if`），如果不存在就创建测试文件。然后执行**上传操作**，上传过程中可能出现网络超时，这时候用 `try` 捕获异常，失败后自动重试，而不会让整个测试脚本崩溃。
